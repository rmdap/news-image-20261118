Entry for the make.fun bounty **"Sum up 18 November's world news in one image"**
(https://make.fun/bounty/news-image-20261118).

A front-page-style image summarising the day's world news: the U.S. strikes
on Iran and Iran's retaliation in the Gulf lead the page, followed by the
Kerch Bridge attack, the Trump–Xi–Putin summit in Shenzhen, the Ebola
outbreak in DR Congo, the Alaska Senate result, Cyclone Xavier, the Siberian
plane crash, Nvidia's earnings, the U.S. losing measles-free status, and the
cold in Gaza's displacement camps. All events happened or were first
reported on Wednesday, 18 November 2026.

## How to run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out python3 main.py
```

This writes `out/entry.png` (1024×1024, ~120 KB). Python 3.13, standard
library only — the program simply copies the bundled `entry.png`.
